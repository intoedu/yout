# 윷 던지기

윷이 없을 때 쓰는 웹 윷 던지기 프로그램입니다. 게임판 없이 윷가락 4개만 던집니다.

## 사용법
- **스페이스바를 길게 눌러** 세기를 모으고, **손을 떼면** 윷이 날아갑니다.
- 휴대폰에서는 **던지기 버튼을 길게 누르세요**.
- 손에 윷을 쥐고 있다가, 손을 떼는 순간 손을 휘둘러 윷이 날아갑니다.
- 게이지는 빠르게(0.45초) 오르내리고, 끝까지 차면 다시 내려옵니다. 빨간 구간(82% 이상)에서 던지면 **낙**이 나올 확률이 크게 올라갑니다.

## 결과
| 결과 | 조건 | 이동 |
|---|---|---|
| 도 | 배 1개 | 1칸 |
| 개 | 배 2개 | 2칸 |
| 걸 | 배 3개 | 3칸 |
| 윷 | 배 4개 | 4칸 · 한 번 더 |
| 모 | 배 0개 | 5칸 · 한 번 더 |
| 빽도 | 도장 찍힌 윷가락 1개만 배 | 뒤로 1칸 |
| 낙 | 윷가락이 멍석 밖으로 나감 | 무효 |
