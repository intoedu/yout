# 윷 던지기

윷이 없을 때 쓰는 웹 윷 던지기 프로그램입니다. 게임판 없이 윷가락 4개만 던집니다.

## 사용법
- **스페이스바를 길게 눌러** 세기를 모으고, **손을 떼면** 손을 펼치며 윷이 날아갑니다.
- 휴대폰에서는 **던지기 버튼을 길게 누르세요**.
- 게이지는 아주 빠르게(0.25초) 오르내립니다.
- **3초 안에** 떼야 합니다. 남은 시간은 멍석 위에 크게 표시됩니다. 3초가 지나면 그 순간의 세기로 자동으로 던집니다.

## 소리
- 세기를 모을 때 올라갔다 내려가는 소리, 1초마다 째깍 소리, 던질 때 바람 소리, 윷가락이 떨어지는 딱 소리, 결과별 효과음이 납니다.
- 던지기 버튼 왼쪽 **소리 켜짐/꺼짐** 버튼으로 끌 수 있습니다.

## 세기 구간
| 구간 | 효과 |
|---|---|
| 0~70% | 보통 확률 |
| 70~85% (화면에는 표시 안 함) | 윷·모가 더 잘 나옴 (끝으로 갈수록 더 잘 나옴) |
| 85~100% (빨간 줄) | **무조건 낙** |

## 팀과 차례
- 기본 2팀(청팀·홍팀), **+ 팀 추가**로 최대 8팀까지 늘릴 수 있습니다. 팀 이름은 눌러서 바꿉니다.
- 화면 위에 지금 **어느 팀 차례**인지 나오고, 배경색이 그 팀 색으로 바뀝니다. 팀별로 무엇이 나왔는지 기록됩니다.
- **윷·모**가 나오면 같은 팀이 자동으로 한 번 더 던집니다.
- 말을 잡았으면 던지기 오른쪽 **잡았다! 한 번 더** 버튼을 누르면, 직전에 던진 팀이 한 번 더 던집니다.
- 왼쪽 위 **순위** 버튼에서 1등 팀부터 차례로 고르면 나머지 등수를 이어서 정할 수 있습니다. 마지막 한 팀은 자동으로 꼴등이 되고, 순위가 정해진 팀은 차례에서 빠집니다. ×를 누르면 그 등수부터 다시 정합니다.
- **새 게임**을 누르면 기록, 차례, 순위가 처음으로 돌아갑니다.

## 결과
| 결과 | 조건 | 이동 |
|---|---|---|
| 도 | 배 1개 | 1칸 |
| 개 | 배 2개 | 2칸 |
| 걸 | 배 3개 | 3칸 |
| 윷 | 배 4개 | 4칸 · 한 번 더 |
| 모 | 배 0개 | 5칸 · 한 번 더 |
| 빽도 | 도장 찍힌 윷가락 1개만 배 | 뒤로 1칸 |
| 낙 | 윷가락이 멍석 밖으로 나감 | 무효 · 차례 넘김 |
